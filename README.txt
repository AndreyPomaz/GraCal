GRASSER 3D PWA CALCULATOR
=========================

Внутри архива:
- index.html    -> Основное приложение калькулятора (работает автономно)
- manifest.json -> Манифест PWA приложения
- sw.js         -> Service Worker для мгновенной работы без интернета (Offline)
- icons/        -> Векторные SVG иконки для рабочего стола мобильного / ПК

КАК ЗАПУСТИТЬ:
1. Локально: просто откройте `index.html` в любом браузере (Chrome, Safari, Edge, Firefox).
2. Как PWA на телефон/планшет:
   - Загрузите эти файлы на любой бесплатный хостинг (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
   - Откройте ссылку на смартфоне:
     • На iOS (Safari): Нажмите кнопку «Поделиться» -> «На экран "Домой"».
     • На Android (Chrome): Нажмите кнопку «Установить приложение» (или меню 3 точки -> «Установить на главный экран»).
